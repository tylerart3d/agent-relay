Local-first by design.

Agent Relay coordinates the services you operate; it does not try to become another model library, cloud account, or opaque gateway.

  • No surprise workloads. Every host starts idle and only loads a model when you request one.
  • No model custody. Agent Relay does not download, copy, or delete your model files.
  • No stream buffering. Responses retain backpressure and cancellation from client to runtime.
  • No forced downtime. Replacing the tray app leaves the independent inference service and loaded model running.
  • Explicit conflicts. Active work must be acknowledged before a force switch or unload proceeds.
  • Private network scope. Peer control uses Tailscale while harness and management routes remain loopback-only.

Built in useful layers.

The control plane is already operating real multi-host fleets. Broader runtime and messaging support is being added without weakening the stable routing core.

Questions, answered.

The short version of the operational decisions behind Agent Relay.

Does Agent Relay run the models itself?

It supervises and routes to configured inference commands through llama-swap. Model binaries and engines remain external, local to each host, and under your control.

Can two computers serve models at the same time?

Yes. Each host can have one active profile in the current implementation, and different hosts can serve concurrently. A client route selects the exact host and profile it should use.

Does the proxy reduce generation speed?

The proxy streams response bodies without buffering or re-encoding them. Network latency still depends on the route, but generation throughput remains dominated by the serving hardware and runtime.

What happens when a laptop goes offline?

The cached host and model catalog stay visible but disabled. When the host returns and its verified peer endpoint responds, Agent Relay brings it back online automatically.

Is Agent Relay open source?

No. The repository is source-visible for evaluation, but Agent Relay's original code, documentation, and artwork are proprietary and all rights are reserved. Bundled third-party components retain their own licenses.
